物业收费登记（Windows）使用说明
================================

【安装与运行】
1. 解压整个压缩包，进入 Tally 文件夹
2. 双击运行 Tally.exe（旁边必须保留 _internal 文件夹）
3. 不要只把 Tally.exe 单独拷贝到其他位置

正确目录结构：
  Tally\
    Tally.exe
    _internal\
    data\              （首次运行后自动创建，存放数据库）
    使用说明.txt

【软件授权】
安装包不包含授权。每次安装后必须在「通用配置 → 软件授权」手动导入 .lic。
到期后有 7 天宽限期；宽限期结束后需更换新的授权文件。
授权文件保存在程序目录 data\license.lic。
（卸载后需重新导入。）

【数据存储】
打包版数据固定保存在程序目录下的 data 文件夹中，不可更改。
请定期备份整个 Tally 文件夹（含 data）。

【卸载】
打开应用 → 通用配置 → 卸载应用。
将删除程序目录、本地数据与配置。

【启动失败时】
1. 确认 _internal 与 Tally.exe 在同一目录
2. 安装 VC++ x64 运行库：
   https://aka.ms/vs/17/release/vc_redist.x64.exe
3. 临时关闭杀毒软件拦截后再试
