## 1. 产品简介

**本地记账**是一款**离线桌面应用**，用于物业/租赁场景下的收费登记与到期提醒，数据保存在本机，无需联网。

### 1.1 能做什么

| 能力 | 说明 |
|------|------|
| 项目管理 | 维护多个物业/楼盘项目 |
| 房间管理 | 按项目维护房间号、面积与租赁状态 |
| 租赁管理 | 登记合同、押金、月租、缴费周期、免租期、折/减（租赁月周期） |
| 收费登记 | 按未缴应收期登记当次缴纳与实缴日期；可看剩余应缴明细 |
| 提醒看板 | 汇总应收逾期/提醒、合同到期；应收类展示剩余应缴公式 |
| 离线授权 | 通过 `.lic` 文件控制使用权，到期后有宽限期 |

### 1.2 推荐使用顺序

```
导入授权 →（必要时确认数据目录）→ 建项目 → 建房间 → 建租赁 → 登记收费 → 看提醒看板
```

## 2. 安装与首次启动

### 2.1 macOS

1. 从发布包解压得到 `Tally.app`（及使用说明）。
2. 将 `Tally.app` 拖到「应用程序」或任意本地文件夹。
3. **首次打开**若提示无法打开/已损坏（未签名）：
   - **方法 A（推荐）**：按住 Control 点击 `Tally.app` →「打开」→ 再点「打开」。
   - **方法 B（终端）**：
     ```bash
     xattr -cr /path/to/Tally.app
     ```
4. 双击启动。本安装包为 **Intel (x86_64)**：
   - Intel Mac：原生运行
   - Apple Silicon（M 系列）：通过 Rosetta 运行

### 2.2 Windows

1. 解压整个压缩包，进入 `Tally` 文件夹。
2. 双击 `Tally.exe` 运行。
3. **务必保留**同目录下的 `_internal` 文件夹，不要只拷贝单独的 `exe`。

正确目录结构示例：

```text
Tally\
  Tally.exe
  _internal\
  data\              （首次运行后自动出现）
  使用说明.txt
```

若启动失败：

1. 确认 `_internal` 与 `Tally.exe` 在同一目录。
2. 安装 [VC++ x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
3. 临时关闭杀毒软件拦截后再试。

### 2.3 首次启动要点

1. **安装包不包含授权**，必须先导入 `.lic`（见第 3 章）。
2. 未授权时：侧栏业务菜单不可用；「通用配置」中仅「导入授权」「卸载」可操作。
3. **打包版**数据目录已固定，无需自选路径：
   - macOS：`~/Library/Application Support/Tally/data`
   - Windows：程序目录下的 `data\`
4. 导入有效授权后，即可使用业务功能。

## 3. 软件授权

### 3.1 规则摘要

| 项 | 说明 |
|----|------|
| 授权文件 | `.lic`（离线文件，需向发行方索取） |
| 导入位置 | 通用配置 → 软件授权 → **导入授权** |
| 宽限期 | 到期日后仍可使用 **7 天** |
| 宽限期结束 | 必须更换新的授权文件 |
| 移除授权 | 同一区域「移除授权」；移除后需重新导入 |
| 重装 / 卸载 | 授权文件会被清除，**重装后需再次导入** |

### 3.2 授权文件存放位置

| 平台 | 路径 |
|------|------|
| macOS | `~/Library/Application Support/Tally/license.lic` |
| Windows | 程序目录 `data\license.lic` |

### 3.3 状态说明

| 状态 | 能否使用业务功能 |
|------|------------------|
| 有效 | 可以 |
| 宽限期 | 可以（请尽快续期） |
| 未激活 / 已过期 / 无效 | 不可以 |

启动时若未激活、过期或无效，会弹出授权对话框，可直接导入。

## 5. 业务操作指南

### 5.1 项目管理

1. 打开「项目管理」。
2. **新建**：填写项目名称并保存。
3. 可按名称搜索；可编辑、删除项目。
4. 点击「管理房间」进入该项目下的房间列表。

> 删除项目前请确认其下房间、合同等数据的处理策略（有外键关联时需按界面提示操作）。

### 5.2 房间管理

1. 选择所属项目，填写房间号、面积（㎡）。
2. 同项目内房间号不可重复。
3. 列表中的 **租赁状态** 由生效合同自动计算：

| 状态 | 含义 |
|------|------|
| 空置 | 无生效合同 |
| 在租 | 有生效合同且未进入到期提醒窗口 |
| 即将到期 | 距到期日 ≤ 配置的「合同到期提前提醒天数」 |
| 已到期 | 已过合同到期日 |

### 5.3 租赁管理

#### 列表与筛选

可按**项目**、**房间号**、**状态**筛选：先选项目后，房间下拉仅显示该项目下的房间；选「全部项目」时房间仅为「全部房间」。

列表主要列：ID、项目、房间、押金、月租金、缴费周期、**租期**、**免租期**、**折/减（月周期）**、状态。

- **免租期**：多段时分行显示；行高随内容增高。
- **折/减（月周期）**：按天展示起止；连续且规则相同的月份合并为一段显示。
- **租期 / 免租期**列按内容收紧宽度，过长时表格可横向滚动（表头与表体同步）。

#### 新建 / 编辑字段

| 字段 | 说明 |
|------|------|
| 项目 / 房间 | 选择房间 |
| 押金、月租金 | 金额 |
| 起租日、到期日 | 合同租期 |
| 缴费周期 | **季度**（默认）/ 半年 / 年 |
| 免租期 | 可设多段，须在租期内且互不重叠；**无需填写免租金额**，由系统按起止日期自动计算 |
| 折/减 | 按「租赁月周期」添加（见下）；类型选「折扣」或「立减」；可一次选择起止月份批量添加 |
| 状态 | 生效 / 结束 |

#### 租赁月周期（折/减起止）

折/减按**起租日对齐**的月片计算，不是自然月。例如：

- 租期 `2026-08-10 ~ 2027-08-09`
- 选择月份 `2026-08` → 实际区间为 `2026-08-10 ~ 2026-09-09`

#### 折/减规则

| 类型 | 规则 |
|------|------|
| 折扣 | 须满足 `0 < 折扣 < 1`（如 `0.85` 表示折后应缴 = 应缴基数 × 0.85） |
| 立减 | 每月减免金额（元），**须大于 0 且不得超过该月周期应缴**（完整月=月租金；非完整月按天折算），否则无法保存 |

#### 免租与折/减如何计入应收

按每个租赁月周期分别计算，再汇总到缴费周期（季度/半年/年）：

1. **应缴**：完整租赁月按月租；若该月因到期日等原因未满整月，则按天比例  
   `应缴 = 月租 × 实际计费天数 ÷ 完整租赁月天数`
2. **整月（整段）免租**：该月净应收为 0，且**不再套用折/减**
3. **否则**：先对应缴基数套用折/减得到折后应缴，再对折后金额按免租重叠天数比例减免  
   - 折扣：折后应缴 = 应缴基数 × 折扣；立减：折后应缴 = 应缴基数 − 立减（不小于 0）  
   - 减免租额 ≈ 折后应缴 ×（免租重叠天数 ÷ 计费天数）  
   - 折/减额 = 应缴基数 − 折后应缴  
4. **剩余应缴**（提醒/登记用）= 应缴 − 已缴 − 免租 − 折/减

操作说明：

- **结束租赁**：将合同标为结束，不再参与提醒计算。
- 同一房间的**生效合同租期不可重叠**。
- 缴费周期用于拆分应收期，并驱动提醒看板与收费登记快捷选项。

### 5.4 收费登记

1. 可按**项目**、**房间号**筛选（选「全部项目」时房间仅「全部房间」）。
2. 登记时从「未缴应收期」选择；缴费起止与费用明细自动带出且不可改，填写**当次缴纳**、实缴日期与备注即可。
3. 费用明细公式：`剩余应缴 = 应缴 − 已缴 − 免租 − 折/减`（应缴为未扣免租/折减的月租合计；非完整租赁月按天比例折算）。
4. 同一应收期内可分多次登记，累计金额**不得超过该期剩余应缴**；未缴清时提醒看板按**剩余应缴**计算。
5. 列表主要列：项目、房间、缴费周期、缴纳金额、实缴日期、**更新时间**（`yyyy-MM-dd HH:mm:ss`）、备注。
6. 支持按当前筛选结果 **导出 CSV**（含上述字段）。

### 5.5 提醒看板

针对状态为 **生效** 的合同，按紧急度排序展示，例如：

- 已逾期（应收）
- 应收提醒
- 合同已到期
- 合同即将到期

排序规则：逾期 → 应收 → 合同已到期 → 即将到期。

| 类型 | 金额列含义 |
|------|------------|
| 应收类（已逾期 / 应收提醒） | **剩余应缴**明细：`剩余应缴 = 应缴 − 已缴 − 免租 − 折/减`（剩余应缴数字标红） |
| 合同类（已到期 / 即将到期） | 月租 |

列表列大致包括：紧急度、类型、项目、房间、剩余应缴、周期。提醒提前天数在「通用配置」中设置（见下章）；启用钉钉推送时，推送文案中的金额公式与看板一致。

## 6. 通用配置

路径：侧栏 **通用配置**。

> 未授权时：仅「导入授权」「卸载」可点，其余输入框与按钮禁用。

### 6.1 基础设置

| 项 | 说明 |
|----|------|
| 应用名称 | 默认「本地记账」，显示在窗口标题等处；改后点「保存配置」 |
| 数据存储位置 | **打包版固定不可改**；开发运行下首次选择并保存后锁定 |

### 6.2 提醒设置

| 项 | 默认 | 含义 |
|----|------|------|
| 合同到期提前提醒天数 | 7 | 到期日前多少天开始出现「即将到期」类提醒 |
| 应收提前提醒天数 | 7 | 应收起始日前多少天开始提醒 |

修改后点击 **保存配置**。

### 6.3 钉钉推送

将「提醒看板」内容通过钉钉**自定义机器人 Webhook** 推送到群。

| 项 | 说明 |
|----|------|
| 启用推送 | 打开后，应用在**联网**且到达设定时间时，**每天推送一次** |
| 推送时间 | 24 小时制 `HH:MM`，默认 `09:00`；到达该时刻后（若应用在运行）触发 |
| Webhook 地址 | 钉钉群 → 智能群助手 → 添加机器人 → 自定义 → 复制 Webhook |
| 加签密钥 | 在钉钉机器人安全设置中选择「加签」，填写 `SEC...` 密钥 |
| 测试推送 | 立即推送当前提醒看板（会先保存当前表单配置） |

说明：

1. 需保持应用在运行；未到点启动时，启动后若已过设定时间且今日未推送，会在联网后补推一次。
2. 无提醒时也会推送「今日暂无提醒」摘要。
3. 断网时跳过，不记为已推送，恢复网络后可再试。

### 6.4 软件授权

见第 3 章：导入 / 移除授权、查看状态与到期日。

### 6.5 应用卸载

见第 8 章。

## 7. 数据备份与恢复

### 7.1 应用内数据库备份（推荐）

通用配置 → **数据备份**（需已授权且存储已就绪）：

| 操作 | 说明 |
|------|------|
| **导出数据库** | 导出当前 `tally.db` 副本，默认名如 `tally-backup-YYYY-MM-DD.db` |
| **导入数据库** | 用选定 `.db` **覆盖**当前全部业务数据；覆盖前自动备份为同目录 `tally.db.bak` |

导入前请确认文件来自本软件导出或兼容结构，否则会提示无效。

### 7.2 整目录备份（额外保险）

| 平台 | 建议备份内容 |
|------|----------------|
| macOS | `~/Library/Application Support/Tally/`（含 `data`、`bootstrap.json`、`license.lic`） |
| Windows | 整个 `Tally` 程序文件夹（含 `data`） |

### 7.3 收费 CSV

「收费登记」页导出的 CSV 便于对账或外部表格使用，**不能替代**完整数据库备份。

## 8. 卸载

1. 打开「通用配置」→「应用卸载」→ **卸载**。
2. 二次确认后执行。

| 平台 | 删除内容 |
|------|----------|
| macOS | `Tally.app` + `~/Library/Application Support/Tally`（数据、配置、授权一并删除） |
| Windows | 整个程序目录 + `%APPDATA%\Tally`（若存在） |

**不可恢复。** 卸载前请先导出数据库或整目录备份。  
开发模式下点击卸载只会提示不可用，不会删文件。

## 10. 运营人员：授权签发

> 仅发行方操作。私钥必须保密，**不要**提交到 Git、不要打进安装包。

### 10.1 前置条件

- 本机已安装 Python 依赖（含 `PyNaCl`）。
- 私钥默认路径：`keys/ed25519_private.key`（仓库已忽略 `keys/`、`*.key`、`*.lic`）。
- 若重新生成密钥对，必须把新公钥同步写入 `app/license.py` 的 `PUBLIC_KEY_B64`，并重新发版，否则旧客户端无法验证新授权。

### 10.2 交互式签发（推荐）

```bash
./scripts/签发授权.sh
# 或
python scripts/issue_license.py
```

按菜单选择「签发授权」，填写客户名称、有效天数或到期日、输出路径即可。默认输出到桌面：`客户名-到期日.lic`。

### 10.3 一键命令

```bash
./scripts/issue.sh "某某物业"           # 默认 365 天，输出到桌面
./scripts/issue.sh "某某物业" 180
./scripts/issue.sh "某某物业" 2027-12-31
./scripts/issue.sh "某某物业" 365 ~/Desktop/某某物业.lic
```

### 10.4 生成密钥对（慎用）

```bash
python scripts/issue_license.py gen-keys
# 覆盖已有密钥：
python scripts/issue_license.py gen-keys --force
```

### 10.5 交付客户

将生成的 `.lic` 发给客户，指导其在应用内：

**通用配置 → 软件授权 → 导入授权**。

## 11. 开发与发布打包

### 11.1 本地开发运行

```bash
cd /path/to/tally
pip install -r requirements.txt
python main.py
```

开发模式下需在「通用配置」中自行选择数据存储目录并保存（保存后锁定）。

### 11.2 本机构建

```bash
pip install -r requirements-build.txt
python scripts/build.py          # 自动识别当前系统
python scripts/build.py mac      # 仅 macOS → dist/Tally.app
python scripts/build.py win      # 仅 Windows → dist/Tally/Tally.exe
```

> PyInstaller **不支持交叉编译**：Mac 只能打 Mac 包，Windows 只能打 Windows 包。

### 11.3 图标

源图：`assets/app-logo.png`。重新生成打包图标：

```bash
python scripts/make_icons.py
```

产出：`app.icns`（macOS）、`app.ico`（Windows）、`app-icon-256.png`（窗口图标）。

### 11.4 CI 发版

推送符合 `v*` 的 Git 标签（如 `v1.0.0`）会触发 GitHub Actions：

- 构建 macOS / Windows 安装包
- 附带平台使用说明
- 创建 GitHub Release 并上传 `Tally-macOS.zip`、`Tally-Windows.zip`

也可在 Actions 中手动 `workflow_dispatch`。

## 12. 常见问题

**Q：打开后什么都不能用？**  
A：先导入有效授权。未授权时只能导入授权或卸载。

**Q：授权到期了还能用吗？**  
A：到期后还有 **7 天宽限期**；宽限期结束后必须导入新的 `.lic`。

**Q：重装后授权没了？**  
A：正常现象。卸载/清除数据会删除 `license.lic`，需重新导入。业务数据若未备份也会丢失，请先备份。

**Q：Windows 提示缺少模块或打不开？**  
A：确认完整解压且保留 `_internal`；安装 VC++ x64；检查杀毒是否拦截。

**Q：macOS 提示已损坏？**  
A：按第 2.1 节用 Control 打开或执行 `xattr -cr`。

**Q：换电脑如何迁移？**  
A：在旧机导出数据库（或拷贝整个数据目录），新机安装并导入授权后，再「导入数据库」。Windows 也可直接拷贝整个 `Tally` 文件夹。

**Q：缴费周期选错了怎么办？**  
A：在租赁管理中编辑该合同的缴费周期；已登记的历史缴费记录不会自动改写，请按需核对。

**Q：免租金额在哪里填写？**  
A：不用填写。新建/编辑租赁时只需配置免租起止日期；系统按「与租赁月周期重叠的天数比例」自动计入应收明细中的免租项。

**Q：折/减选了某月，为什么起止不是 1 号到月末？**  
A：折/减按**起租日对齐**的租赁月周期，不是自然月。例如起租 8 月 10 日，选 8 月对应 `8/10 ~ 9/9`。

**Q：立减提示不能超过该月周期应缴？**  
A：立减上限是该租赁月周期的应缴基数。完整月上限为月租金；若因到期日等导致非完整月，上限按 `月租 × 实际天数 ÷ 完整月天数` 折算。

**Q：公钥提交到仓库有没有风险？**  
A：没有。公钥用于验签，本来就要打进客户端；**私钥**才必须保密。
